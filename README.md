# navbytes/homebrew-tap

Homebrew tap for [navbytes](https://github.com/navbytes) tools.

```sh
brew tap navbytes/tap
```

| Package | Install | What it is |
|---|---|---|
| [roost](https://github.com/navbytes/roost) | `brew install navbytes/tap/roost` | Session-native terminal multiplexer for AI agent CLIs. Prebuilt binaries (macOS/Linux, arm64/x86_64), checksum-verified. |
| [vee](https://github.com/navbytes/vee) | `brew install --cask navbytes/tap/vee` | Native macOS menu-bar script runner. Apple Silicon, macOS 26+. |
| [nt](https://github.com/navbytes/nt) | `brew install --cask navbytes/tap/nt` | Terminal task & note manager — durable memory for AI coding sessions. |

`brew upgrade` picks up new releases.

## Notes

- `Casks/vee.rb` is generated by Vee's release workflow
  ([`scripts/update-homebrew-cask.sh`](https://github.com/navbytes/vee/blob/main/scripts/update-homebrew-cask.sh))
  on every release — edit that script, not the cask here.
- `Formula/roost.rb` is copied from
  [`packaging/homebrew/roost.rb`](https://github.com/navbytes/roost/blob/main/packaging/homebrew/roost.rb)
  in roost's repo (the source of truth) on every release. roost previously
  lived in `navbytes/homebrew-roost`, which now just redirects here.

Issues and pull requests belong in each tool's own repo, not here.
